## 🛠️ Tech Stack

- **Web:** HTML5, Modern CSS3 (`@keyframes`, CSS Custom Properties), SVG, Vanilla JavaScript, Web Audio API.
- **Android:** Kotlin, Jetpack Compose, Coroutines, Animatable / GraphicsLayer, Haptic Feedback.
